# philvdm.co.za — game portfolio

Personal game portfolio for Phil VDM. First featured title: **Echoes of the Terminal**.

## Edit content

Update games, copy, and email in:

`src/content/site.ts`

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Deploy the folder to Vercel, then point `philvdm.co.za` DNS at it.
